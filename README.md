# Cours Grok Bot — v2 (projets)

https://wn5zw4s89s-svg.github.io/cours-grok-bot/

Structure pilotée par `contenu/projets.json` (projet → leçons ; `niveaux.json` reste accepté en repli).
Noms de projet : titre du quiz `PROJET-N.quiz.json`. Badge : « badge **X** » dans la dernière leçon du projet.
Encadrés `attention` commençant par **Défi X.** → encadré `defi`.
Gamification localStorage : XP, série 🔥, chemin, badges, confettis, partage X.

    npm install && npm run build
