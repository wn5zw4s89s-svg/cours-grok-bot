# Leçon 36 : Confie du code à un agent cloud

<p class="chapeau">Un agent qui travaille dans le cloud, seul, et rend son travail. Aujourd'hui : lecture et démo.</p>

## Agent cloud

Même agent, mais sur une machine dans le cloud. Ton Mac peut être éteint.

Il clone le dépôt, travaille sur une branche, teste, et rend son travail (avec captures, vidéos, journaux).

Lancement : cursor.com/agents, Cursor (choix **Cloud** sous la zone de demande), Slack, GitHub…

<div class="box attention" markdown="1">
**Aucun achat. Aucun lancement aujourd'hui.**  
Page cursor.com/pricing relue le 15/10/2026 : « Cloud agents & automations » à partir de **Premium, 30 $/mois** (hors taxes). Le plan **Free (0 $)** n'en a pas.  
La doc ajoute : facturation au tarif API du modèle, avec une limite de dépense à fixer au premier usage.  
Prendre un plan payant : à toi seul de décider, un jour ou jamais.
</div>
