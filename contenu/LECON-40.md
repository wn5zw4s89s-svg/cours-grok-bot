# Leçon 40 : Fais construire une app par des bots

<p class="chapeau">Une idée. Une page de besoin. Un prototype local. Rien en ligne.</p>

## Le projet

**Site vitrine de Marc** : accueil, services, urgences, contact fictif. Point de départ : `page-marc` (niveau 5).

L'ordre :

1. Besoin écrit (1 page).
2. Règles (`AGENTS.md`).
3. Prototype local.
4. Tests (liste de contrôle).

Projet plus gros : Cursor propose les **Projects** — un agent coordinateur planifie et délègue.

<div class="box atoi" markdown="1">
**À toi de jouer.** 2 à 3 requêtes à l'agent Cursor (plan gratuit OK).

1. Écris `BESOIN.md` : but · 4 pages · ce qui est interdit (prix, vraies coordonnées).
2. Complète `AGENTS.md` : « Lis BESOIN.md avant chaque changement. »
3. Agent (`Cmd+I`) : « Construis le site décrit dans BESOIN.md, en local. »
4. Ouvre `index.html`. Vérifie : 4 pages ✅/❌ · liens entre pages ✅/❌ · aucun prix ✅/❌ · pied de page fictif ✅/❌.
5. Un ❌ -> une demande précise, une seule.

**C'est réussi si :** BESOIN.md (1) ; règle ajoutée (2) ; 4 points vérifiés dans le navigateur (4).
</div>
