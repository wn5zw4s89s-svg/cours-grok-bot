# Leçon 41 : Mets ton app en ligne avec un agent cloud

<p class="chapeau">Le prototype marche en local. La mise en ligne est publique. Aujourd'hui : préparer et comprendre.</p>

## Le chemin

1. Le code va dans un dépôt (GitHub, GitLab…).
2. Un agent cloud clone le dépôt, travaille sur une **branche**, teste.
3. Il rend une demande de fusion (PR) avec des captures.
4. **Toi** tu relis et tu décides de fusionner, puis de publier.

Agents cloud : plan payant (Premium, 30 $/mois hors taxes sur cursor.com/pricing, lu le 15/10/2026). Facturés au tarif API du modèle, avec une limite de dépense.

<div class="box attention" markdown="1">
Lecture et démo. **Aucun achat, aucun dépôt public, aucune mise en ligne aujourd'hui.** Chaque geste réel : si tu le décides.
</div>

<div class="box atoi" markdown="1">
**À toi de jouer.** Sans agent.

1. Écris la demande à l'agent cloud. Forme : « Sur la branche … , ajoute … . Teste … . Rends une PR avec captures. Ne publie rien. »
2. Écris ta liste de relecture de la PR : 4 points.
3. Écris où la page serait publiée et qui la verrait. Forme : « Publiée sur … ; visible par … . »
4. Écris ta décision : « Je publierai si … . Sinon j'attends. »

Exemple (autre sujet) : « Sur la branche horaires, ajoute les horaires d'été. Rends une PR. »

**C'est réussi si :** demande avec « Ne publie rien » (1) ; 4 points (2) ; public identifié (3) ; décision conditionnelle (4).
</div>

<div class="box corrige" markdown="1">
**Demande :** « Sur la branche site-marc, ajoute la page Urgences. Ouvre-la dans un navigateur et fais une capture. Rends une PR. Ne publie rien. »  
**Relecture :** aucun prix · coordonnées fictives · liens OK · capture jointe.  
**Publication :** GitHub Pages ; visible par tout le monde.  
**Décision :** je publierai si Marc (fictif) valide le texte. Sinon j'attends.
</div>
