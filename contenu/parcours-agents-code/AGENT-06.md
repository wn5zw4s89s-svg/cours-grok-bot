# Agent 6 · Publie la page

Objectif : à la fin, tu as un lien public ouvreable sur iPhone, sans rien payer.

## Étape 1 · Fusionne seulement si tu es d'accord (1 min)

La pull request (PR) propose d'intégrer la branche dans `main`. C'est **irréversible** côté contenu une fois fusionné (on peut corriger après, mais le merge est un vrai choix).

<div class="box atoi" markdown="1">
**À toi :** copie ce bloc seulement si la page te convient sur iPhone :

> Si la pull request de l'agent cloud est bonne, merge-la dans main. Sinon, dis-moi ce qui bloque. Rien de payant.

C'est réussi si le bot confirme le merge, ou liste ce qui bloque.
</div>

<div class="box corrige" markdown="1">
**Exemple de réponse :** « PR fusionnée dans main. » ou « Pas encore : le bouton Mentions légales manque. »
</div>

## Étape 2 · GitHub Pages (2 min)

Pour une vitrine simple, **GitHub Pages** publie gratuitement depuis un dépôt public.

Rappel du cours (leçon 23 / leçon 49) : GitHub Pages **interdit la vente en ligne**. Pas de panier. Une page d'accueil + liens, oui.

<div class="box atoi" markdown="1">
**À toi :** copie ce bloc et envoie-le à ton bot :

> Publie ce dépôt sur GitHub Pages, gratuitement, branche main. Donne-moi le lien en *.github.io avant d'annoncer que c'est fini. Aucun nom de domaine payant.

C'est réussi si tu reçois un lien `…github.io…` et que tu l'ouvres sur iPhone.
</div>

<div class="box corrige" markdown="1">
**Exemple de réponse :** « En ligne : https://ton-pseudo.github.io/champ-libre-accueil/ »
</div>
