# Agent 1 · Comprends ce qu'est un agent de code

Objectif : à la fin, tu sais ce qu'est un agent de code, et quand le laisser coder à ta place.

## Étape 1 · Deux rôles, pas un (1 min)

Ton bot Grok Bot (ex. Lumen) **pilote**.

L'**agent de code** (agent cloud Cursor) **écrit le code**, sur un ordinateur à distance. Pas sur ton iPhone.

Ton iPhone : tu parles au bot. Le bot : il lance l'agent. L'agent : il code, teste, pousse le résultat.

<div class="box atoi" markdown="1">
**À toi :** qui écrit le code : ton bot Grok Bot, ou l'agent de code ?

C'est réussi si tu nommes un seul rôle.
</div>

<details class="solution"><summary>Voir la réponse</summary><div class="box corrige" markdown="1">

L'agent de code. Ton bot Grok Bot lance et suit le travail. Il ne tape pas le code à ta place.

</div></details>

## Étape 2 · Pourquoi un agent cloud (1 min)

Un agent cloud tourne dans une machine isolée, dans le cloud. Ton téléphone peut rester fermé.

Il clone un dépôt, travaille sur une branche à part, puis pousse le résultat pour que tu le récupères.

Ancien nom : « Background Agents ». Même chose.

<div class="box atoi" markdown="1">
**À toi :** ton iPhone doit-il rester ouvert pendant que l'agent code ?

C'est réussi si tu réponds par oui ou par non.
</div>

<details class="solution"><summary>Voir la réponse</summary><div class="box corrige" markdown="1">

Non. L'agent a sa propre machine. Ton iPhone peut être fermé.

</div></details>

## Étape 3 · Quand l'utiliser (1 min)

Utilise un agent de code pour : une page web, un bug, une fonction, un site.

Ne l'utilise pas pour : répondre à un client, trier des emails, écrire un post. Là, ton bot Grok Bot suffit.

Fil rouge de ce parcours : la **première page** d'un concurrent d'Hipcamp (camping entre particuliers). Tu l'appliques ensuite de bout en bout dans la partie Hipcamp du cours.

<div class="box atoi" markdown="1">
**À toi :** pour « construire la page d'accueil d'un site de camping », tu lances un agent de code ?

C'est réussi si tu réponds par oui ou par non.
</div>

<details class="solution"><summary>Voir la réponse</summary><div class="box corrige" markdown="1">

Oui. C'est du code. L'agent de code construit. Ton bot pilote.

</div></details>

## Étape 4 · Ce qu'il faut déjà avoir (1 min)

Sans ça, l'agent ne démarre pas :

1. Un compte Cursor **payant** (les agents cloud demandent un plan payant).
2. Grok Bot (inclus dans les plans Cursor payants individuels et Teams).
3. Plus tard : un dépôt GitHub (ou « partir de zéro » sans dépôt).
