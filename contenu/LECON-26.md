# Leçon 26 : Prépare un bot à partager sans secret

<p class="chapeau">Tu vas partager un modèle. Ce qui est dans la fiche devient public pour qui a le lien.</p>

## Ce qu'un modèle montre

**Share** -> **Create template**. Le lien peut être **Public link** ou **Team-only**.

Le destinataire ouvre une page sur x.ai, puis **Add to Grok Bot**. Il obtient une **copie**. Pas ton ordinateur, pas tes connexions, pas ton historique.

Le modèle montre : identité, description, skills, routines.

<div class="box erreur" markdown="1">
Laisser dans la description : clé API, URL interne, vrai client, vrai numéro. Tout ce que tu ne mettrais pas dans un document public.
</div>

<div class="box atoi" markdown="1">
**À toi de jouer.** Sans le bot.

Liste de contrôle « avant de partager », une ligne par point. Forme : « - … »

1. Relis la description de Le siphon (ou Le devis). Barre tout secret ou donnée réelle.
2. Écris 6 lignes de contrôle. Inclure au moins : secrets / données client / URL internes / skills / routines / qui peut ouvrir le lien.
3. Pour chaque ligne, note ce que tu feras (garder / retirer / vérifier).

Exemple (autre sujet) : « - Aucune clé API dans la description. »

**C'est réussi si :** 6 lignes (2) ; chaque ligne a une action (3) ; aucun vrai client dans ta liste.
</div>

<div class="box corrige" markdown="1">
- Aucune clé API ni mot de passe.  
- Aucun vrai nom, téléphone, adresse client.  
- Aucune URL interne.  
- Skills : uniquement des recettes sans données personnelles.  
- Routines : aucune qui lit un fichier privé.  
- Lien : Public ou Team-only — je choisis avant de créer le lien.
</div>

<div class="fin" markdown="1">
## En résumé

- Modèle = copie pour l'autre. Pas ton ordi ni tes logins.
- Ce qui est dans la fiche peut être lu.
- Liste de contrôle avant tout lien.

**Bravo !** Leçon 27 : dupliquer et partager.
</div>
