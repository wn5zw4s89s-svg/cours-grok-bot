# Leçon 45 : Top 1 % : la skill du goût maison

<p class="chapeau">Quatre bots, quatre styles. Le client le sent. Donne-leur un seul goût.</p>

## Une skill

Une skill, c'est une méthode enregistrée. Tous tes bots peuvent l'utiliser.

Tu l'écris une fois. Toute l'équipe la suit.

## Côte à côte

| Équipe moyenne | Équipe top 1 % |
|---|---|
| Chaque bot écrit à sa façon | Un seul « goût maison » |
| Le style vit dans 4 fiches | Le style vit dans une skill |
| Tu corriges 4 fois | Tu corriges une fois |

## Ce que dit une bonne skill

Quand l'utiliser. Ce qu'il faut. Les étapes. Comment vérifier. Ce qu'on rend. Ce qui demande ton accord.

## Modèle à coller

```
Enregistre une skill nommée "Goût maison ___".
Quand : avant tout texte ou visuel montré à un client.
Ton : 3 phrases max, un fait par phrase, signé ___. Jamais "n'hésitez pas", "ravi", "sublimer".
Visuel : couleurs du logo seulement, aucun emoji, aucun dégradé violet.
Références : ___, ___, ___.
Vérifier : relis avec cette liste avant de rendre.
Accord : tout envoi ou publication attend ma validation.
```

<div class="box atoi" markdown="1">
**À toi de jouer.** 3 étapes. 3 messages.

1. Envoie au groupe : « @Plume écris un post sur Figue. @Lumen écris la réponse à "c'est livré quand ?". » Garde les deux textes : version moyenne.
2. Complète le modèle avec tes projets 2 et 4. Envoie-le à Chef.
3. Renvoie au groupe la même demande, avec « Utilisez la skill Goût maison. » Compare.

**C'est réussi si :**

- tu as les deux textes d'avant (étape 1) ;
- Chef confirme que la skill est enregistrée (étape 2) ;
- les deux nouveaux textes suivent la même skill, sans tic ni emoji (étape 3).
</div>
