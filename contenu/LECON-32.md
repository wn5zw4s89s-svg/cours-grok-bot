# Leçon 32 : Fais tes premiers pas avec un agent de code

<p class="chapeau">Tu sais parler à un bot. Un agent de code, c'est pareil, mais il écrit des fichiers.</p>

## L'agent

Un agent de code lit, modifie des fichiers, lance des commandes. Cursor le fait sur un Mac. **Ici, ton bot Grok Bot le fait sur son ordinateur cloud** — depuis ton iPhone.

Trois pièces : **instructions** (règles), **outils** (fichiers, commandes, recherche), **modèle**.

## Le point de sauvegarde

Avant un gros changement, un bon agent garde une **copie d'avant**. S'il se trompe, tu lui demandes d'annuler. Les messages restent.

<div class="box info" markdown="1">
Peu de crédits. Une demande courte et précise par exercice.
</div>

<div class="box atoi" markdown="1">
**À toi de jouer.** 0 message pour l'instant. Prépare.

1. Écris dans Notes ta première demande. Forme : « Sur ton ordinateur, crée le dossier /workspace/page-marc. Dedans, crée index.html : … . Une seule page. Pas de bibliothèque externe. »
2. Relis : titre, téléphone fictif, un bouton, « une seule page ».

Exemple (autre sujet) : « Crée index.html : titre "Boulangerie Exemple", horaires, téléphone 06 00 00 00 01. »

**C'est réussi si :** demande écrite dans Notes (1) ; « une seule page » + coords fictives (2).
</div>

<div class="box corrige" markdown="1">
« Sur ton ordinateur, crée /workspace/page-marc/index.html : titre "Marc Garnier, plombier", une phrase "Dépannage à Ville-Test", téléphone 06 00 00 00 01, un bouton "Appeler". Une seule page. Pas de bibliothèque externe. »
</div>
