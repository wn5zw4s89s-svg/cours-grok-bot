# Leçon 32 : Fais tes premiers pas avec l'agent Cursor

<p class="chapeau">Tu sais parler à un bot. Un agent de code, c'est pareil, mais il écrit des fichiers.</p>

## L'agent

L'agent de Cursor fait seul des tâches de code : il lit, modifie les fichiers, lance des commandes.

Ouvre-le dans le panneau de côté : `Cmd+I`.

Trois pièces : **instructions** (règles), **outils** (fichiers, terminal, recherche), **modèle**.

## Le point de sauvegarde

Avant un gros changement, l'agent crée un **checkpoint** : une photo des fichiers.

Il se trompe ? Clique le checkpoint dans le fil -> le bouton Restore Checkpoint de Cursor, qui revient à l'état d'avant. Les fichiers reviennent. Les messages restent.

<div class="box atoi" markdown="1">
**À toi de jouer.** Aucune requête à l'agent.

1. Crée un dossier vide `page-marc` sur le Bureau.
2. Ouvre Cursor -> le bouton Open Folder de Cursor, qui ouvre un dossier -> `page-marc`.
3. Appuie sur `Cmd+I`. Le panneau de l'agent s'ouvre. N'envoie rien.
4. Écris dans Notes ta première demande. Forme : « Crée un fichier index.html : … . Une seule page. Pas de bibliothèque externe. »

Exemple (autre sujet) : « Crée index.html : titre "Boulangerie Exemple", horaires, téléphone 06 00 00 00 01. »

**C'est réussi si :** dossier ouvert dans Cursor (2) ; panneau agent vu (3) ; demande écrite, avec « une seule page » (4).
</div>
