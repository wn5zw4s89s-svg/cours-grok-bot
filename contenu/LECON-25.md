# Leçon 25 : Fais passer le relais entre bots

<p class="chapeau">Crée Le devis. Ouvre un groupe. Lance. Le relais doit être visible.</p>

## Groupe et relais

1. Barre de gauche : nouvelle conversation.
2. Coche 2 à 6 bots.
3. Ouvre le groupe. Renomme-le si besoin.


Un bot peut écrire à un autre bot. Le destinataire se réveille. Tu vois le relais dans la conversation.

<div class="box attention" markdown="1">
Dans un groupe : pas de cartes d'approbation, pas de brouillons e-mail/Slack, pas de demandes de secret. Les messages de relais entre bots sont du texte seulement.
</div>

<div class="box atoi" markdown="1">
**À toi de jouer.** Peu de crédits. Données fictives.

1. Crée le bot **Le devis** (crée un nouveau bot). Colle Nom, Titre, Description (leçon 24).
2. Nouvelle conversation -> coche **Le siphon** et **Le devis** -> ouvre le groupe. Nom : `Atelier Marc`.
3. Envoie ton message de lancement + ce SMS fictif : « Mme Roux, 06 00 00 00 01, 12 rue Test. Ça goutte sous l'évier. C'est combien ? »
4. Relis le fil. Note : qui a répondu en premier · le relais visible · aucun prix ferme · rien d'envoyé.
5. Note ✅/❌ + une phrase de chaque bot.

**C'est réussi si :** Le devis créé (1) ; groupe à 2 bots (2) ; relais visible (4) ; ✅/❌ avec phrases (5).
</div>

<div class="box corrige" markdown="1">
Le siphon : fiche sans prix.  
Le devis : brouillon de devis, cases prix vides ou « à remplir par Marc ».  
Relais visible dans le fil. Rien publié.
</div>

<div class="box preuve" markdown="1">
Relais ✅ (message de Le siphon vers Le devis, ou réponse de Le devis après la fiche) · Aucun prix ✅ « … » · Rien envoyé ✅
</div>

<div class="fin" markdown="1">
## En résumé

- Groupe = 2 à 6 bots, un résultat commun.
- Relais visible dans le fil.
- Preuve = phrases des bots.

**Bravo !** Leçon 26 : préparer un partage.
</div>
